# Shield Minimal

**轻量 · 高速 · 难以察觉的个人广告拦截扩展**

基于 Chrome Manifest V3 与 `declarativeNetRequest` 构建，无构建步骤、无第三方依赖、无遥测上报。

[安装](#安装) · [使用](#使用) · [规则格式](#规则配置格式) · [开发](#本地开发)

## 特性

| | 能力 | 说明 |
|---|---|---|
| 🛡️ | **网络层拦截** | 通过 `declarativeNetRequest` 动态规则在浏览器内核层拦截广告请求，页面无感知、不占用 JS 线程 |
| 🎭 | **元素级隐藏** | 注入样式规则移除广告容器与追踪占位元素，保留页面布局稳定 |
| 👻 | **反检测对抗** | 在页面主世界伪造广告 SDK 全局变量、劫持弹窗与强制点击层，规避常见的广告拦截探针 |
| ⚡ | **热更新** | 导入新规则后立即生效并刷新当前标签页，无需重载扩展 |
| 🎛️ | **域名级开关** | 一键关闭/恢复指定域名的全部拦截，网络层与内容脚本同步生效 |
| 📦 | **纯静态** | 无 `package.json`、无构建产物，仓库即成品，可直接审计每一行代码 |

## 工作原理

扩展采用三层递进的拦截架构，覆盖从网络请求到页面渲染的完整链路。

**第一层 · 网络请求拦截**
后台 Service Worker 将规则配置中的 URL 模式转换为 `declarativeNetRequest` 动态规则。匹配命中的请求由浏览器网络栈直接拦截，页面 JavaScript 不会感知到请求曾经发出。

**第二层 · 元素隐藏**
隔离世界的内容脚本在页面加载时生成隐藏样式并注入页面，移除广告位、推广位与追踪像素占位。当前选择器为内置列表，站点专属的 COSMETIC 规则尚未接入（详见「已知限制」）。

**第三层 · 反检测对抗**
主世界内容脚本在 `document_start` 阶段运行，早于页面自身脚本。它伪造 `adsbygoogle`、`googletag` 等广告 SDK 的存在形态，劫持 `window.open` 以吞掉广告弹窗，并识别、拆除覆盖全屏的透明强制点击层。

**域名级开关**
后台为三层拦截提供统一的开关编排：为被关闭的域名写入优先级更高的 `allow` 放行规则，同时把该域名加入内容脚本的 `excludeMatches`。网络请求与页面脚本在同一次切换中一并放行或恢复。

## 安装

### 开发者模式加载（推荐）

1. 打开 `chrome://extensions/`
2. 右上角开启 **开发者模式**
3. 点击 **加载已解压的扩展程序**
4. 选择本仓库根目录（含 `manifest.json` 的那一层）
5. 建议将扩展固定到工具栏，点击盾牌图标即可唤出面板

> 源码目录不含签名文件，本地加载后仅对当前浏览器实例生效。修改任何代码后需回到扩展管理页点击 **重新加载**。

## 使用

点击工具栏盾牌图标唤出控制面板：

- **顶部状态区** —— 显示当前站点域名与过滤状态，拨动开关即可关闭/恢复本站的全部拦截
- **已关闭拦截的域名** —— 列出所有被放行的域名，可随时单项恢复
- **统计区** —— 展示累计拦截次数与当前生效的规则数量
- **规则同步与管理** —— 支持本地 JSON 导入 / 导出备份，以及远程订阅地址拉取
- **底部状态栏** —— 显示底层驱动引擎

### 规则配置格式

导入与导出的 JSON 结构如下：

```json
{
  "version": "1.0.1",
  "updatedAt": "2026-11-11",
  "networkRules": [
    "*://*.doubleclick.net/*",
    "*://*.googlesyndication.com/*"
  ],
  "cosmetics": {
    "global": [
      ".adsbygoogle",
      "[id^=\"google_ads_\"]"
    ],
    "domains": {
      "example.com": [
        "div[class*=\"sponsor\"]",
        "aside[class*=\"ads\"]"
      ]
    }
  }
}
```

| 字段 | 类型 | 说明 |
|---|---|---|
| `version` | `string` | 规则集版本号 |
| `networkRules` | `string[]` | URL 匹配模式，交由 `declarativeNetRequest` 拦截 |
| `cosmetics.global` | `string[]` | 全站生效的 CSS 选择器 |
| `cosmetics.domains` | `object` | 以域名为键、选择器数组为值的站点专属规则 |

> 导入时会对文件做结构校验与字段补齐，容忍缺失字段并兼容 `cosmeticRules` 等历史命名，校验通过后热更新生效。

## 本地开发

仓库不依赖任何构建工具或包管理器，源码即运行产物。

```bash
# 校验 manifest.json 合法性
jq . manifest.json

# 本地预览弹窗界面（可选）
python3 -m http.server 8080

# 提交前自检
git diff --stat
```

**目录结构**

```
.
├── manifest.json              # MV3 清单：权限、Service Worker 与面板入口（内容脚本由后台动态注册）
├── background/
│   └── service_worker.js      # 规则存储、DNR 动态规则同步、消息路由
├── popup/
│   ├── popup.html             # 面板结构
│   ├── popup.css              # 面板样式（CSS 变量集中于 :root）
│   └── popup.js               # 面板交互：开关、导入导出、远程同步
├── scripts/
│   ├── main_world_hook.js     # 主世界：反检测、弹窗与强制点击对抗
│   └── content_isolated.js    # 隔离世界：元素级隐藏
├── icons/                     # 16 / 48 / 128 px 图标
└── AGENTS.md                  # 贡献者指南
```

## 隐私与权限

本扩展**不收集、不上传任何用户数据**，全部配置保存在浏览器本地 `chrome.storage.local` 中。

| 权限 | 用途 |
|---|---|
| `declarativeNetRequest` | 拦截广告网络请求 |
| `storage` | 本地保存规则配置与站点白名单 |
| `tabs` | 识别当前标签页域名以实现站点级开关 |
| `scripting` | 按需注入过滤脚本 |
| `<all_urls>` | 在所有站点生效广告过滤 |

## 已知限制

- 拦截统计的读写链路尚未打通，统计数值暂不更新
- 域名白名单仅精确匹配被记录的域名本身，其子域名不自动继承放行
- 部分站点具备主动的扩展检测能力，可能出现整页蒙层提示；本扩展已内置多层反检测对抗，但并非所有站点均可绕过
